Course Content

Nine Modules. One Delivery Sequence.

Taught in the order a real Salesforce implementation follows, from data model to deployed agent.

CRM fundamentals, the sales and service lifecycle, Salesforce navigation, standard and custom objects, fields, relationships, record types, page layouts, Lightning App Builder, data import and data quality.

Users, profiles, permission sets and permission set groups, roles, organisation-wide defaults, sharing rules, field-level security, and how to map a business requirement to the right access model.

Record-triggered, screen, scheduled and autolaunched Flows, validation rules, approval processes, formula fields, error handling, debugging and when to choose automation over code.

Apex syntax, SOQL and SOSL, triggers and trigger frameworks, classes, asynchronous Apex, governor limits, bulkification, test classes and deployment basics.

Component structure, HTML templates, JavaScript, Lightning Data Service, Apex wire and imperative calls, events, component communication, and placing components on record pages and apps.

Agent Builder, topics and instructions, standard and custom actions built from Flows and Apex, Prompt Builder, grounding agents in Salesforce data and knowledge, the Einstein Trust Layer, testing conversations, and deploying agents to service and sales teams.

Prompting for requirements analysis, generating and reviewing Apex and LWC, explaining errors and debug logs, writing test classes, producing user documentation, and a review checklist for AI-generated code.

Requirements gathering, solution design, data model, automation, code, Agentforce agent, testing, documentation and demonstration across the industry scenarios below.

Resume building, portfolio presentation, scenario-based interview practice, and the job readiness assessment.
